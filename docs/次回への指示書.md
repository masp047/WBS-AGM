# 次回への指示書（第11期以降の定時株主総会）

初版作成日：2026年8月20日
最終更新：第10期総会の終了後に更新する（WBSのK-01）

第10期の総会を担当したわたしたちから、次に担当する人への引き継ぎです。
この文書とWBSテンプレートがあれば、次回は迷わず回せる状態を目指しています。

## 1. 最初に読むべき3行

1. **第11期からは公開会社です。** 招集通知は総会の日の2週間前までに発送してください。
2. **基準日は4月30日、総会は7月30日までに開催してください。** 1日でも過ぎると基準日が使えなくなり、第10期と同じ手戻りが起きます。
3. **決算公告を毎期忘れないでください。** 総会終結後、遅滞なく自社サイトに掲載します。

## 2. 第10期からの変更点

第10期の総会で譲渡制限を撤廃したため、会社の区分が非公開会社から公開会社に変わりました。
これにより、次回から以下が変わります。

| 項目 | 第10期まで | 第11期から | 根拠 |
|---|---|---|---|
| 招集通知の期限 | 総会の日の1週間前まで | **総会の日の2週間前まで** | 会社法299条1項 |
| 取締役の任期 | 10年まで伸長可 | **2年**（選任後2年以内に終了する事業年度に関する定時株主総会の終結時まで） | 会社法332条1項・2項 |
| 監査役の任期 | 10年まで伸長可 | **4年** | 会社法336条1項・2項 |
| 事業報告の記載事項 | 非公開会社の記載で足りる | **公開会社としての追加記載が必要**（主要な借入先、上位株主の状況、会社役員に関する事項、社外役員に関する事項など） | 会社法施行規則119条以下 |
| 株式の譲渡 | 取締役会の承認が必要 | **承認手続は不要** | 定款変更により |
| 公告方法 | 官報 | **電子公告**（自社サイト） | 定款変更により |

第10期総会で選任された役員の任期は次のとおりです。

- 取締役：第12期（2027年5月1日〜2028年4月30日）に関する定時株主総会の終結の時まで
- 監査役：第14期（2029年5月1日〜2030年4月30日）に関する定時株主総会の終結の時まで

**取締役については第12期の総会、つまり2028年の総会で改選が必要です。忘れないでください。**

## 3. 第11期の標準スケジュール

決算日と基準日はともに4月30日です。基準日から3か月以内という制限があるため、
**総会は7月30日までに開催しなければなりません**（会社法124条2項）。

| 時期 | 実施事項 |
|---|---|
| 4月30日 | 決算日・基準日 |
| 5月上旬 | 決算作業の開始。監査役会と監査報告の通知期限を合意しておく |
| 5月中旬〜6月上旬 | 計算書類・事業報告・附属明細書の作成 |
| 6月上旬 | 計算書類等を監査役会へ提供（受領日を必ず記録する） |
| 6月中旬〜下旬 | 監査役会による監査 |
| 6月下旬 | 監査報告の受領 |
| 7月上旬 | 取締役会（計算書類の承認、招集事項の決定） |
| **7月上旬〜中旬** | **招集通知の発送（総会の日の2週間前まで）** |
| **7月下旬（7月30日まで）** | **定時株主総会の開催** |
| 総会後2週間以内 | 役員変更等の登記（発生する年のみ） |
| 総会後遅滞なく | 決算公告（自社サイトに掲載、5年間の継続掲載） |

法人税・地方税の申告期限との関係は、顧問税理士に確認してください。
申告期限の延長特例を受けている場合とそうでない場合で、総会の位置づけが変わります。

## 4. 総会が7月30日を過ぎそうなときの対処

第10期で実際に起きた事態です。同じことを繰り返さないための手順を残します。

**まず、遅れそうだと分かった時点で早めに手を打ってください。**
第10期では気づくのが遅れ、結果として開催が事業年度末から5か月以上ずれ込みました。

基準日を過ぎてしまった場合の選択肢は2つです。

**(A) 新たな基準日を設定して公告する**
取締役会で新基準日を定め、その2週間前までに公告します（会社法124条3項）。
官報の場合は掲載までに1〜2週間かかるため、合計で3〜4週間が必要です。

**(B) 基準日を定めず、総会時点の株主名簿上の株主に招集する**
基準日は任意の制度です（会社法124条1項）。株主数が限られており名簿が確定していれば、
名簿上の株主全員に招集することで足ります。第10期はこの方法を採りました。

株主数が少なく異動がないうちは(B)が速いですが、公開会社になって株主が増え、
株式の異動が頻繁になると(B)は使いにくくなります。そのときは(A)を前提に、
公告の手配期間を織り込んだ日程を組んでください。

## 5. WBSの使い方

Googleスプレッドシート「日本信達株式会社　定時株主総会　WBS」を複製して使います。

1. 表題と対象期を書き換える
2. B2セル（開催日）に今回の開催予定日を入れる。これで全ての予定日が動く
3. B3セル（作業開始可能日）に着手できる日を入れる。C4セルに警告が出たら開催日が早すぎる
4. その期に不要な作業（配当がない年など）はステータスを「対象外」にする
5. 週次で進捗を確認し、着手日と完了日の実績を必ず記入する

**実績日の記入を怠ると、次の代の人が所要日数を見積もれなくなります。**
第10期の実績が入った状態のWBSが `docs/WBS_第10期定時株主総会.md` に残っています。

## 6. その期に応じて追加が必要なタスク

WBSの標準形には入っていないため、該当する年は追加してください。

- **剰余金配当を行う年**：分配可能額の算定、配当議案の作成、効力発生日と支払開始日の設定、源泉徴収、支払調書の提出、未払配当金の管理
- **役員を改選する年**：候補者の確定、就任承諾書と本人確認証明書の事前取得、監査役選任議案への監査役会の同意（会社法343条）、登記
- **定款を変更する年**：新旧対照表の作成、特別決議での可決、登記
- **株主が増えた場合**：株主名簿管理人の設置の検討、招集通知の印刷・発送の外注化の検討
- **株主が1000名以上になった場合**：書面投票の採用が義務になります（会社法298条2項）

## 7. つまずきやすい箇所

第10期で実際に注意を要した点です。

1. **監査役会との監査報告の通知期限**　法定は4週間ですが合意により短縮できます。ここを早めに握れるかで日程が2〜3週間変わります
2. **添付書類の差し替え**　監査報告の添付漏れは決議取消事由になり得ます。発送前の最終確認を必ず二人で行ってください
3. **委任状の回収**　定足数の確保はここにかかっています。大株主への事前説明を早めに
4. **電子公告のURL**　URLは登記事項です（会社法911条3項28号イ）。登記されたURLと実際のURLが一致していないと公告として認められません。**サイトの改修でURLが変わるときは変更登記が必要です。**Web担当者にもこの点を伝えておいてください
5. **決算公告の継続掲載**　電子公告の場合、5年間の掲載が必要です。サイトのリニューアル時に消さないよう、引き継いでください
