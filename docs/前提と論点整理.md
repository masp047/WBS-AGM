## 3. 論点1　基準日をどう扱うか

### 事実

定款上の基準日は4月30日です。基準日株主が権利を行使できるのは基準日から3か月以内であり
（会社法124条2項）、その期限は2026年7月30日で既に経過しています。
つまり4月30日を基準日とした議決権行使は、今回の総会ではできません。

### 検討した選択肢

**(A) 新たな基準日を設定して公告する**
取締役会で新基準日を定め、その2週間前までに公告します（会社法124条3項）。
官報は申込から掲載まで1〜2週間かかるため、公告手配から基準日確定まで3〜4週間を要します。

**(B) 基準日を定めず、総会時点の株主名簿上の株主に招集する**
基準日は会社が任意に定めることができる制度です（会社法124条1項）。
定めない場合、議決権を行使できるのは総会時点の株主名簿上の株主です。

### 判断

**(B)を採用しました。**

株主が33名で名簿が確定しており、名簿上の株主全員に招集すれば議決権行使者の確定に支障がないためです。
公告の手配が不要になり、最短日程が3〜4週間前倒しできます。

### (B)を採ることによる留意点

基準日という基準時点を置かないため、招集通知の発送後から総会当日までに名義書換があると
議決権者がずれます。この期間の取扱いを事前に決めておく必要があります（WBSのB-05）。
また、4月30日以降に株式の異動がなかったことを確認しておく必要があります（同B-02）。

## 4. 論点2　譲渡制限の撤廃がもたらす連鎖

譲渡制限を撤廃すると、その効力が生じた時点で会社は公開会社になります。
単独の定款変更では終わらず、以下が連動します。

### (1) 役員の任期がその場で満了する

譲渡制限を廃止する定款変更の効力発生により、在任中の取締役および監査役の任期は
法律上満了します（会社法332条7項、336条4項）。
このため役員選任議案は必須であり、上程順序は「定款変更が先、役員選任が後」となります。
役員選任は定款変更の効力発生を条件とする形で整理します（WBSのD-07）。

### (2) 機関設計

公開会社は取締役会の設置が必須であり（会社法327条1項）、取締役会設置会社は監査役を
置く必要があります（同条2項）。
当社は取締役会・監査役会とも設置済みのため、**機関設計に関する定款変更は不要**です。
なお監査役会は3名以上で、その半数以上が社外監査役である必要があります（会社法335条3項）。

### (3) 役員の任期が短縮される

非公開会社の任期伸長特例（10年）が使えなくなり、取締役は2年、監査役は4年になります。
次回以降の選任サイクルが変わります。

### (4) 招集通知の期限が変わる

今回の総会は非公開会社のまま招集するため、招集通知は総会の日の1週間前までで足ります
（会社法299条1項）。
**第11期からは公開会社として2週間前が必須**になります。ここを取り違えると次回が違法になります。

### (5) 登記

株式の譲渡制限に関する規定の廃止、公告方法の変更、役員変更の3件が発生します。
いずれも効力発生日から2週間以内に申請します（会社法915条1項）。

## 5. 論点3　公告方法と決算公告

### 事実

決算公告は、定時株主総会の終結後遅滞なく行う義務があります（会社法440条1項）。
公開・非公開を問わず、また会社の規模も関係ありません。**今回の第10期分から必要です。**
未了は過料の対象になり得ます（会社法976条2号）。

### 判断

公告方法を電子公告へ変更する定款変更を、今回の第1号議案に含めます。

- 電子公告のURLは登記事項です。実際に電子公告を使えるのは登記完了後になります
- 決算公告を電子公告で行う場合、5年間の継続掲載が必要です（会社法940条1項2号）
- 電子公告は通常は調査機関の調査を要しますが、**決算公告については調査が不要**です（会社法941条）
- サーバー障害等に備え、予備的公告方法（官報等）を定款に定めておくのが実務です（会社法939条3項）

第9期以前の決算公告が実施済みかどうかも確認します（WBSのI-09）。

## 6. 日程と工数の考え方

開催日を先に決めず、作業を洗い出してから逆算する方針で組んでいます。

### 工数と期間は別物

WBSでは次の2つを分けて管理しています。混同すると見積りが実態から大きくずれます。

- **所要時間（分）** … その作業に人が張り付く時間。待ち時間は含みません
- **着手日から完了日まで** … 暦の上での期間。監査待ち・相手方の回答待ちを含みます

たとえばC-06「監査役会による監査の実施」は、社内の工数は90分ですが、監査期間として
2週間を見込んでいます。開催日を決めているのは工数ではなく、この待ち時間と法定期限です。

### 日程は工数から自動計算する

WBSに日付を手で置くのはやめ、所要時間から計算する形にしました。

- **所要日数** ＝ 所要時間 ÷ 1日あたりの投入時間（切り上げ）。待ち時間のある作業は最低所要期間を優先します
- **総会前** … 完了日が法定期限などで決まっているため、そこから所要日数だけ営業日を遡って着手日を出します
- **総会当日** … 着手日と完了日はいずれも開催日です
- **総会後** … 着手できる日が決まっているため、そこから所要日数だけ営業日を進めて完了日を出します

期限が土日に当たる場合は前営業日へ、着手できる日が土日に当たる場合は翌営業日へ寄せます。

動かせるつまみは2つです。**開催日**と**1日あたりの投入時間**。
投入時間を増やせば日程が縮み、減らせば伸びます。所要時間を書き換えれば、
その行の日程だけが伸縮します。

### 工数の見積り基準

AIを使って下書きを作る前提で見積もっています。

| 目安 | 対象 |
|---|---|
| 30分 | 確認・連絡・記録などの単発作業 |
| 60分 | 資料1点の確認、短い文書の作成 |
| 90分 | 条文と突き合わせるチェック、集計作業 |
| 120分 | 関係者との調整を伴う作成物 |
| 180分 | 手作業を含む定型業務 |
| 240分（0.5人日） | ゼロから作る主要文書。AIで下書きし、人が推敲・検証する |

会議は実際の会議時間で計上します。1人日は480分（8時間）で換算します。

全83タスクの合計は6,720分（112時間、14.0人日）です。2名で分担するため、
1人あたりおよそ7人日相当になります。

### 最短開催日

- 1日あたりの投入時間を240分（1人・半日）としたとき、最も早い作業は開催日の39日前から始まります
- 作業開始可能日を2026年8月24日とすると、**最短の開催日は2026年10月2日**です
- スプレッドシートには暫定値として2026年10月6日（火）を入れています

A・B・D の各カテゴリは既にほぼ完了しているため、実際の律速は監査の期間です。
計算書類を監査役会へ正式に提供した日から数えて35日後が、現実的な最短の開催日になります。

### 日程を左右する要素

**監査役会の監査報告（C-04からC-07）**
監査報告の通知期限は、計算書類等を受領した日から4週間を経過した日が原則ですが、
監査役会と取締役の合意により短縮できます（会社計算規則124条1項、会社法施行規則132条1項）。
ここを合意できるかで開催日が2〜3週間変わります。工数はわずか30分ですが、
日程短縮の最大のポイントです。

**書面投票を採用するかどうか（E-03）**
書面投票を採用すると、非公開会社であっても招集通知は総会の日の2週間前までとなります
（会社法299条1項括弧書き）。
株主33名であれば委任状方式で足りるため、採用しない前提で組んでいます。
