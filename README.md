## スプレッドシートの使い方

**B2セル（開催日）を書き換えると、全ての予定日が自動で動きます。**
開催日はまだ確定していないため、暫定値として2026年10月6日を入れてあります。

| セル | 内容 |
|---|---|
| B2 | 開催日（D）。ここを変えると83件すべての予定日が動く |
| B3 | 作業開始可能日。この日より前に着手日が来ると計画が成り立たない |
| B4 | 全作業のうち最も早い着手日。B3より前になるとC4セルに警告が出る |
| F2〜F4 | 総タスク数・合計所要時間・人日換算 |
| I2〜I4 | 増田・境それぞれの主担当分の所要時間、未完了の所要時間 |

青文字のセルが手入力欄です。着手日（実績）・完了日（実績）・ステータスと、B2・B3の
2つのパラメータがこれにあたります。黒文字のセルは計算結果または確定値です。

## 所要時間の考え方

所要時間は「その作業に人が張り付く時間」です。着手日から完了日までの期間とは別物で、
監査待ちや相手方の回答待ちといった待ち時間は含みません。AIで下書きを作る前提で
見積もっています。

| 目安 | 対象 |
|---|---|
| 30分 | 確認・連絡・記録などの単発作業 |
| 60分 | 資料1点の確認、短い文書の作成 |
| 90分 | 条文と突き合わせるチェック、集計作業 |
| 120分 | 関係者との調整を伴う作成物 |
| 180分 | 手作業を含む定型業務 |
| 240分（0.5人日） | ゼロから作る主要文書。AIで下書きし、人が推敲・検証する |

会議は実際の会議時間で計上します。1人日は480分（8時間）で換算します。

## 列の構成

当初いただいた11列に、4列を加えています。

- **No.** … 会議での参照用
- **先行作業** … 順序を守るため。公告や通知の順序が崩れると手続の瑕疵になる
- **期限区分・根拠** … 「法定」と「社内」を区別する。動かせない日程が一目で分かる
- **ステータス** … 未着手／進行中／完了／保留／対象外

## データを直すとき

`scripts/build_wbs.py` の `TASKS` を編集して実行すると、Excel・CSV・Markdownが
まとめて作り直されます。

```
python3 scripts/build_wbs.py
```

スプレッドシート側を直接編集した場合は、忘れずにこちらにも反映してください。
次回の標準形はこのスクリプトが土台になります。
