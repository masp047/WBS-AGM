## スプレッドシートの使い方

**B2セル（開催日）を書き換えると、全ての予定日が自動で動きます。**
開催日はまだ確定していないため、暫定値として2026年10月20日を入れてあります。

- B3セル：作業開始可能日。この日より前に着手日が来ると計画が成り立ちません
- B4セル：全作業のうち最も早い着手日。B3より前になるとC4セルに警告が出ます
- F2・F3セル：総タスク数と想定総工数（実績が入ると実績ベースに切り替わります）

実績日を入れると、実施日数が予定ベースから実績ベースへ自動で切り替わります。
土日を除いた営業日で数えています。

## 列の構成

当初いただいた11列に、4列を加えています。不要であれば削除して構いません。

- **No.** … 会議での参照用
- **先行作業** … 順序を守るため。公告や通知の順序が崩れると手続の瑕疵になります
- **期限区分・根拠** … 「法定」と「社内」を区別する。動かせない日程が一目で分かります
- **ステータス** … 未着手／進行中／完了／保留

## データを直すとき

`scripts/build_wbs.py` の `TASKS` を編集して実行すると、CSVとMarkdownが作り直されます。

```
python3 scripts/build_wbs.py
```

スプレッドシート側を直接編集した場合は、忘れずにこちらにも反映してください。
次回の標準形はこのスクリプトが土台になります。
